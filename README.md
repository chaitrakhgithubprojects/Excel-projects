# excel-sales-performance-analysis
 # Sales Performance Analysis – Excel Mini Project

## Objective
Analyze sales performance using Excel formulas.

## Dataset
Raw sales data with date, salesperson, region, and amount.

## Excel Formulas Used
- SUM
- AVERAGE
- IF
- SUMIF
- COUNTIF
- MAX / MIN

## Analysis Performed
- Total sales calculation
- Performance classification
- Highest and lowest sales identification

## Tools Used
- Microsoft Excel
- GitHub
